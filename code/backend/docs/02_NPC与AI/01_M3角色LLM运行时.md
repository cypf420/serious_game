# M3 真实角色 LLM 运行时

更新时间：2026-07-23

## 运行边界

真实模型只负责生成 NPC 可见台词及受限软状态候选。签约户数、预算、全局指标、旗标、事实释放、强制决策、事件与结局轴仍由权威规则层决定。模型调用发生在“短预留”和“短提交”之间，不持有数据库锁。

## 玩家自助配置与服务器默认接口

网页登录流程会在账号验证后要求玩家选择个人 API 或服务器默认接口。个人 API 通过一次正式结构契约测试后，凭据只保存在后端内存并绑定当前登录会话；退出、过期或后端重启后失效。所有角色、夜间、群组、会议、文书和合同模型调用在请求开始时冻结同一个会话级网关，模型调用失败时按错误契约返回，不生成替代台词。

个人接口仅接受公共 HTTPS OpenAI Chat Completions 兼容地址；禁止内网、回环、保留地址、URL 用户信息、查询参数、片段和重定向。只读复盘不依赖模型配置。

## 可选的管理员 Qwen 配置

管理员需要提供“服务器默认接口”时，再复制 `.env.example` 为 `.env` 并填写 API Key。若 `ROLE_LLM_PROVIDER=none`，服务器不提供默认接口，玩家个人 API 仍可独立运行。代码与日志不得保存或输出密钥。

```dotenv
ROLE_LLM_PROVIDER=openai_compatible
ROLE_LLM_BASE_URL=https://api.qianzhang-ai.cn/v1
ROLE_LLM_MODEL=qwen3.6-plus
ROLE_LLM_API_KEY_ENV=DASHSCOPE_API_KEY
DASHSCOPE_API_KEY=
```

供应商使用 JSON mode，本地使用 Pydantic 严格 Schema 校验。鉴权错误 401/403 是不可重试配置错误；个人接口和服务器默认接口均不允许静默降级。产品运行时只接受 `none` 或 `openai_compatible`，确定性替身仅用于 `tests/` 的依赖注入。

## 真实连通性验收

第三方 OpenAI 兼容端点 `https://api.qianzhang-ai.cn/v1/chat/completions` 已在 2026-07-23 完成真实接口复验。`qwen3.6-plus` 回答通过结构、枚举、知识边界、目标事实和软状态一致性校验，随后完成 D1–D90 回放：76 个硬决策、89 次夜间结转。账本、选择序列和终局均与固定种子基线一致。审计仅有 1 条 `openai_compatible/succeeded` 记录，共 3971 tokens、无重试、无降级。

该服务为第三方兼容层。正式生产部署前仍应单独确认余额告警、服务商并发/RPM/TPM、数据保存政策、流式输出和长上下文稳定性；这些属于部署与供应商治理，不改变 M3 已完成的游戏运行时边界。
