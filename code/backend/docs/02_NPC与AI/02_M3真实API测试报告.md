## 测试中发现并修复的问题

1. 供应商可能在对白中正确披露已授权事实，但漏填 `disclosure_id`；单个对白还可能同时自然涉及多个已授权事实，而旧单值校验无法表达。现将该字段定义为“本回合主要披露事实”：仅在全部内容仍处于白名单内、且可由唯一事实或唯一目标事实确定时由服务端补齐；命中禁区、无法唯一判断或 ID 与对白不一致时仍拒绝。真实复测通过。
2. 老倔头、苗喜旺、邓守本、蒋崇岳、罗健、崔广林原先缺少运行时角色设定。现按《最终剧本》的轻量配角与蒋崇岳硬约束补齐，不新增剧情旗标或结算。
3. 有限角色曾提交态度或焦虑变化候选。提示词现按 `state_tier` 明确要求四个变化字段全部为 `none`，服务端原有拒绝规则继续保留；相关角色真实复测通过。
4. 蒋崇岳首次复测把玩家误称为“老陈”。上下文现固定注入玩家身份“李致远，云溪县县长”，再次真实复测后正确称呼“致远同志”。
