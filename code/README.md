# 游戏产品代码区

本目录承载可玩游戏产品的全部代码。旧剧本生成、修订和审稿工具已经从仓库移除。

- `backend/`：权威游戏后端、结构化剧本包与当前文字协议。
- `frontend/terminal/`：无图片的最小文字测试客户端；只消费玩家 API。
- `frontend/` 的其他形态：待美术和正式交互方案冻结后再创建。

当前 M0–M3 文字运行时与 optimization-0.5 玩法闭环已完成，可沿默认路径从 D1 回放至 D90：选择出身、处理固定与条件事件、使用政策工具、提交编号及配套决策、通过真实 Qwen 角色互动、执行逐日夜间模拟，并在 D90 按母稿首命中规则生成结构化终局。SQLite 存档、调用审计与 NPC 记忆均支持重启继续；全量内容和 LLM 安全边界均纳入自动化校验。
