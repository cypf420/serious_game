## 审查结论与证据

判断标准：某项机制若不能贡献资源取舍、人物协商、时间压力、程序依据或数据正确性，就不应要求玩家额外操作。不能因为代码步骤多，就删除保证账务正确性的内部校验。

| 当前机制 | 结论 | 理由 |
| --- | --- | --- |
| 现金、预算、房源、服务选择 | 保留 | 对应真实共享资源及不同住户诉求，接受后实际扣除；预算用途限制是否合理属于另一项平衡审查，不能仅凭下拉框判断冗余 |
| 搬离、交房与过渡安排 | 有住房时保留 | 后端检查可交付日、面积档位和晚交房的过渡安排；过渡月份还影响补偿标准 |
| 无住房方案仍填写交房日 | 应简化 | 前端始终 required；后端在判断是否有住房之前验证交房日；该日期没有相应交房事项 |
| 保存方案并预览，再提交签约 | 保留 | 前一步确认条款且不占资源，后一步按本户实际条件判定并可能立即结算，两次操作后果不同 |
| 固定合同正文、自动政策校验 | 保留 | 避免正文和真实承诺不一致；不再需要手动改正文、生成模型或专业审校模型 |
| 逐户签署与同批次切换 | 保留 | 代表的表态不能替代每户同意，符合逐户签约目标 |
| 答复版本、协商后重提与防重复抽取 | 后端保留、教程轻讲 | 防止旧意见误对应新方案，确保重复提交不重复结算；不再随机抽取人物是否愿意签约；无需教玩家输入指纹等实现细节 |
| 补充批文 | 按需要说明 | 超标准加款有正式授权条件；常规方案不要求玩家把所有文件逐份勾选 |
| 旧合同确认与历史原文 | 兼容层保留 | 防止更新时丢失旧约定；仅旧未签草案需要提示，不纳入所有新手必学步骤 |

## 任务二：按真实合同阶段提供教程

**文件：** `code/frontend/web/app/tutorial/types.ts`、`definitions.ts`、`TutorialProvider.tsx`，以及 `code/frontend/web/app/GameShell.tsx`。

**接口约定：** 为 `TutorialContext` 增加可选 `contractStage: "terms" | "preview" | "feedback" | "signed" | "legacy" | null`。阶段由 ContractWorkspace 的实际编辑状态、签署状态及当前版本答复产生；不能仅看 contract.status 推断玩家是否正在编辑。新增独立 `contract.ts` 中的 `contractTutorial(stage): TutorialDefinition`；章节稳定 ID 为 `scene:contract:<stage>`，每阶段独立 revision。对应更新 Provider 的合同弹窗匹配和目录恢复规则，其他场景保持原匹配。

- [ ] 为合同对象栏、金额及预算组、住房日期组、服务组、保存按钮、预览及扣除摘要、提交按钮、反馈与协商按钮、签署结果添加稳定 `data-tutorial-id`。
- [ ] 编辑阶段卡片正文如下：
  1. **先确认这一户**：核对当前家庭与签约人。代表可以协商多户，但每户合同独立，只有本户接受才计入签约。
  2. **安排补偿**：现金默认按本户政策标准填写。结合诉求和可用预算调整；超出授权时，按提示补充有效批准依据。
  3. **安排住房与时间**：选择住房后核对房源、交房和搬离日期。晚交房需要过渡安排；不采用实物安置时无需填写交房日。
  4. **分配配套服务**：按本户需要安排服务名额。资源由各户共用，先看库存；草案暂不占用，签署时再次核验。
  5. **保存方案**：点击“保存方案并预览合同”后，系统核验并保存方案，此时尚未签约或扣款。游戏自动保存已完成的操作；未保存的表单修改仍需先保存。
- [ ] 预览阶段两张卡：
  1. **核对合同与扣除**：核对只读正文、现金、住房和服务。需要调整时点击“修改方案”，不要在合同正文中另写承诺。
  2. **提交本户签约**：核对无误后自行提交。满足本户实际条件后，合同生效并立即扣除款项和资源；未满足时不扣除，答复只表达顾虑。
- [ ] 反馈阶段一张卡：**按答复继续协商**：有疑问可返回入户会谈解释或核实。修改条款后先保存；实际事项变化后，也可再次提交同一方案；单纯增加会谈次数不等于满足条件。
- [ ] 签署阶段一张卡：**本户已签署**：本户合同已生效，约定款项与名额已结算。同批次其他住户仍需各自办理；不暗示存在独立的交房或治疗操作入口。
- [ ] 旧草案阶段单独提示核对旧约定，再明确确认生成当前方案；不显示给新草案玩家。
- [ ] 教程只讲解当前页面已有目标。关闭教程后由玩家实际保存或提交，再在下一阶段邀请；不通过教程“下一步”模拟业务阶段切换。未保存错误停留编辑阶段。
- [ ] 最后一步使用“讲解完成，自主操作”，聚焦当前保存、提交或协商按钮；目标未就绪时暂停，不能判为已完成。
