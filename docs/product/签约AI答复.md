# 签约 AI 答复

2026-09-09：正式签约调用当前账号绑定的真实模型网关，任务 review_contract。业务规则锁定 accept/explain，网关只做一次表达请求，不再让模型选择是否签约。输入包含人物设定、本人和代表的相关会谈、历史方案及答复、当前方案和一处尚存顾虑。输出用人物语言回应方案变化，不能添加未实现的手续或泄露完整条件清单。

返回文本原样存入答复，历史记录附 response_source 和 model_id。接口报错/空答复中止本次写入，不用模板兜底，不签署、不扣款。相同输入复用已存答复；新版指纹允许旧模板答复重新生成一次。已经签署的合同不重新调用。

个人 API 仍采用原有登录期内存保存；重启服务会失效，需要重新启用。可使用已有服务器默认配置。不要把 API 密钥写入文档或日志。
