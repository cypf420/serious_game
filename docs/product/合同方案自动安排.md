# 合同方案自动安排

2026-09-09 实施。玩家填写基础补偿、住房和服务；日期、月份和预算分项不再手填。

- 浏览器保存发送 auto_arrange=true，cash_amount 是基础补偿。旧客户端仍能使用旧字段，已签合同不变。
- 搬离日 min(当前日+20,90)，交房日 max(搬离日,房源可交付日)。未选住房不产生交房承诺或等待交房补偿。
- 过渡月数 ceil((交房日-搬离日)/30)。补偿按配置 transition_per_person_month × 安置人口 × 月数，向上取整到万元。
- 基础补偿不得低于不含过渡的政策标准；补偿总额为基础补偿加过渡补偿。合同正文列明两项和总额。
- automatic_arrangement 存储基础金额、过渡金额及 budget_allocations。基础补偿记 property_land，过渡补偿记 moving_transition_reward，总财政余额扣总额；分项仍受预算约束。
- 期房可在合同中约定未来交付，但签约即占用一套库存；服务仍须已开放。不新增日终交房或搬离事件。
- 重复保存不再次累加过渡补偿；编辑默认使用已存基础补偿。签约按已预览方案结算，不在提交时重新增加金额。
- 旧草案继续原样查看，点击修改并保存才转换；已签合同不改正文或账务。

验证：tests/test_contract_auto_arrangement.py；e2e/budget-sync.spec.ts；e2e/contract-tutorial.spec.ts。
