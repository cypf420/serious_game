# 签约判定边界

正式提交仍校验方案版本、资金、资源、日期和家庭实际条件。全部通过后签署，不再调用人物模型选择无限反报价，也不允许人物另加自由文本条款作为门槛。

未通过时只表达一项尚未满足的真实顾虑，不列出完整条件或操作步骤。合同资源未落实与人物的额外想法分开：会谈中的想法不能自动成为签约条件。

签约指纹增加判定版本。历史拒签不被改写，但不再阻止玩家按新规则重新提交原方案。只有玩家点击提交才会签署及扣款。

验证：合同记账及方案流程 36 项测试通过；另两项验证 WU-03 通过现有表单填写住房、复检及学位后可签署、重复提交不重复扣款，以及未满足答复不暴露解法清单。以上为隔离测试存档的接口验证，未操作玩家存档。
